# homebrew-tap

> **Personal tap.** The formulae here are built for my own use and are unlikely
> to be suitable for general use without modification.

## Usage

```
brew tap sschlesier/tap
```

## Formulae

| Formula | Description |
|---|---|
| `bkup` | Nightly backup to a restic/Backblaze B2 repository with launchd WakeSystem support |
